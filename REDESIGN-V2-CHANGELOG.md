# Wish Craft — Unified Redesign V2 Changelog

- Re-composed the global page atmosphere around Phase-2 Rose / Plum / Gold tokens.
- Standardized typography around Plus Jakarta Sans + Playfair Display, with Dancing Script retained only as an accent where already used.
- Preserved the original Phase-2 logo across site chrome and recipient experiences.
- Standardized borders, radii, shadows, button language, card surfaces, and spacing rhythm.

## Creator pages

- Added compact explanation/trust sections below the creation UI.
- Improved template selection, form focus, preview framing, and mobile stacking.
- Added a subtle typing/focus response without changing data behavior.
- Removed the old page-specific footer card and credit block from the creator experience.

## Other surfaces
- Unified Card Studio styling.
- Unified My Wishes collection presentation.
- Unified QR/share presentation.
- Unified Thank You Card presentation and removed duplicate legacy top bar.
- Unified About, Contact, Privacy, Terms, and Admin presentation.
- Added the same Wish Craft logo mark to recipient template experiences.
